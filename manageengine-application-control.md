# ManageEngine Application Control Plus: How Application Whitelisting Works

Installing software is easy. Keeping track of what runs across an entire company network is a different story. An application that seems harmless can become a security risk if it contains malicious code or has more permissions than it needs.


ManageEngine [Application Control](https://golicense.net/product-category/network-license/manageengine/application-control/) Plus addresses this challenge through application control and privilege management. It helps IT teams identify installed applications, decide which programs users can run, and limit access based on predefined rules.

## Why Application Whitelisting Matters

Application whitelisting allows only approved programs to run on managed devices. Instead of relying entirely on detecting known threats, organizations can restrict unapproved software from running in the first place.

This approach also makes software management easier. Employees often have applications they no longer use or do not need for their jobs. Limiting access to relevant tools can reduce unnecessary software and simplify maintenance.

## How Application Control Plus Works

The process starts by identifying applications installed across endpoints. Administrators can then create rules based on trusted software vendors, application names, digital certificates, or file hashes.

These rules help determine which executable files are allowed to run. If a file changes, its hash may change as well, requiring the policy to be reviewed.

## Managing Access by User Role

Different employees need different applications. Application Control Plus allows administrators to associate application policies with individual users or groups, helping keep access aligned with job responsibilities.

Combined with least-privilege principles, this approach can reduce unnecessary access and strengthen endpoint security.
